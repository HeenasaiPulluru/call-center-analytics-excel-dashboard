# 📊 Call Center Analytics Dashboard (Excel Project)

## 🧠 Project Overview
This project analyzes call center performance using Microsoft Excel, leveraging Pivot Tables, Power Pivot (Data Model), and an interactive dashboard.

It delivers insights into customer behavior, representative performance, revenue trends, and service quality to support data-driven decision-making.

---

## 🎯 Objectives
- Analyze customer call patterns  
- Measure customer satisfaction levels  
- Evaluate representative performance  
- Identify high-value and low-value customers  
- Analyze call center workload trends over time  

---

## 📂 Dataset Information
The dataset contains **1000 call records** with the following fields:
- Customer ID  
- Call ID  
- Representative (R01–R05)  
- City (Cincinnati, Cleveland, Columbus)  
- Call Date  
- Call Duration  
- Purchase Amount  
- Satisfaction Rating  

---

## 📊 Key KPIs
- Total Calls: **1000**  
- Total Revenue: **$96,623**  
- Total Call Duration: **89,850**  
- Average Rating: **3.9 / 5**  
- 5-Star Calls: **307**

---

## 📈 Analysis Performed

### 📞 Customer Analysis
- Call frequency per customer  
- Top 10 customers by revenue  
- High-call vs low-purchase behavior  

### 😊 Customer Satisfaction
- Rating distribution (1–5 stars)  
- Average satisfaction score  
- Satisfaction by representative  

### 👨‍💼 Representative Performance
- Revenue generated per representative  
- Call handling distribution  
- Performance comparison (R01–R05)  

### 📅 Time-Based Analysis
- Monthly call trends  
- Weekly workload patterns  
- Peak business days  

### ⏱ Call Duration Analysis
- Short / Medium / Long call categorization  
- Relationship between call duration and satisfaction  

---

## 📊 Dashboard Features
- Pivot Tables for dynamic analysis  
- Interactive slicers (Rep, City, Customer)  
- KPI summary cards  
- Conditional formatting heatmaps  
- Charts and trend visualizations  

---

## 💡 Key Insights
- Tuesday is the busiest day for calls  
- A small group of customers generates most revenue  
- Representative **R02** handles the highest workload  
- Average customer rating is **3.9 / 5**  
- Call duration shows mixed impact on satisfaction  
- Columbus region shows strong revenue concentration
