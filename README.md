# Call-center-analytics-excel-dashboard
This project analyzes call center performance using Microsoft Excel, including Pivot Tables, Power Pivot (Data Model), and interactive dashboards. It provides insights into customer behavior, representative performance, revenue trends, and service quality.
# 📊 Call Center Analytics Dashboard (Excel Project) ## 🧠 Project Overview This project analyzes call center performance using Excel Pivot Tables, Data Modeling, and interactive dashboards. It helps understand customer behavior, agent performance, revenue distribution, and service quality. --- ## 🎯 Objectives - Analyze customer call patterns - Measure customer satisfaction levels - Evaluate representative performance - Identify high-value and low-value customers - Study call center workload trends over time --- ## 📂 Dataset Information The dataset contains 1000 call records with the following fields: - Customer ID - Call ID - Representative (R01–R05) - City (Cincinnati, Cleveland, Columbus) - Call Date - Call Duration - Purchase Amount - Satisfaction Rating --- ## 📊 Key KPIs - Total Calls: **1000** - Total Revenue: **$96,623** - Total Duration: **89,850** - Average Rating: **3.9** - 5-Star Calls: **307** --- ## 📈 Analysis Performed ### 📞 Customer Analysis - Call frequency per customer - Top 10 customers by revenue - High-call-low-purchase customers (Time Wasters) ### 😊 Customer Satisfaction - Average rating analysis - Rating distribution (1 to 5 stars) - Satisfaction by representative ### 👨‍💼 Representative Performance - Revenue per representative - Call handling distribution - Performance comparison across R01–R05 ### 📅 Time-Based Analysis - Monthly call trends - Busiest weekdays - Seasonal workload patterns ### ⏱ Call Duration Analysis - Duration bucketing (Short / Medium / Long) - Relationship between duration and satisfaction --- ## 📊 Dashboard Features - Pivot Tables for dynamic analysis - Interactive slicers (Rep, City, Customer) - KPI summary cards - Conditional formatting heatmaps - Customer-wise revenue matrix - Trend and performance charts --- ## 💡 Key Insights - Tuesday is the busiest day for calls - A small group of customers contributes most revenue - Representative R02 handles the highest workload - Customer satisfaction average is stable at 3.9 - Call duration has mixed correlation with satisfaction - Columbus region shows strong revenue density --- ## 🛠 Tools Used - Microsoft Excel - Pivot Tables - Power Pivot (Data Model) - Conditional Formatting - XLOOKUP - Charts & Slicers --- ## 🚀 Project Outcome This dashboard helps business stakeholders: - Improve customer service efficiency - Identify high-value customers - Optimize staffing during peak hours - Improve representative training programs give me from starting like repository name etc
